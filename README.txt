CHOICE NUTRITION LTD WEBSITE — REVISED EDITION
================================================

HOW TO RUN
1. Extract the ZIP file.
2. Keep the folders and files in the same structure.
3. Open index.html in a browser, or use VS Code Live Server.

WHAT'S INCLUDED
- Responsive business website with company, product catalogue and contact sections.
- 20 products, including MCP (Monocalcium Phosphate).
- Product descriptions and custom product illustrations.
- No product prices are displayed.
- Existing listed pack sizes are retained. MCP pack size is shown as available on request because no size was supplied.
- Searchable product catalogue.
- WhatsApp enquiry links on every product and a floating WhatsApp contact link.
- Clickable telephone numbers, email and website links.

PROJECT FILES
- index.html: page structure and company content
- css/style.css: responsive design, layout and visual styling
- js/products.js: product information and catalogue rendering
- js/main.js: mobile menu, reveal animations and footer year
- images/: company logo and product illustrations
